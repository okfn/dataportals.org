Comprehensive list of Open Data Portals around the world. The list is
maintained by Open Knowledge with the input of the open data community and
experts. The data is used to power the online site at https://dataportals.org/.

`countries.csv` lists the allowed values for `portals.csv`'s `country` column. It's a copy of [datasets/country-list](https://github.com/datasets/country-list) plus Kosovo (`XK`), refreshed monthly by the [Update Country List](../.github/workflows/update_countries.yml) workflow, so don't edit it by hand.
